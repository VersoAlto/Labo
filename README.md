# Le Labo

L'atelier de Verso Alto : la méthode et les pièces pour fabriquer, client
par client, des plateformes à gamification immersive.

Le Labo n'est pas une application qu'on lance. C'est un dépôt dans lequel
une session de Claude entre pour un client donné, lit la méthode, et
construit sa plateforme sur mesure.

## Commencer un client

1. Copier `clients/_gabarit/` en `clients/<nom-du-client>/`.
2. Ouvrir une session sur ce dépôt et dire : « On commence l'entretien pour
   <nom-du-client>. »
3. Suivre les cinq temps décrits dans `CLAUDE.md`.

## État au 11 novembre 2026

- La méthode est écrite à partir de la lecture de Maisons Vaillantes.
  Elle n'a encore servi pour aucun client : c'est une hypothèse de travail.
- La réserve contient deux pièces : le générateur de vitrines et le banc
  de test des bases de données.
- Il n'y a pas encore de socle technique commun (comptes, rôles,
  cloisonnement entre clients). Voir `reserve/README.md`.
